# marbaji-claude

Mo's personal Claude Code skills marketplace.

## Skills

### inventory-checker
Displays a complete inventory of all installed Claude Code components — MCP servers (Local vs Cloud, with status), plugin marketplaces, available skills (grouped by marketplace), npm/Python/Homebrew packages, and CLI tools.

### mos-obsidian-memory
Project-first session memory using Obsidian. At session end, updates project docs and current-focus before writing lean session logs. Presents a summary with categories (ChalkTalk vs Personal) for approval before writing.

## Install

```bash
claude plugin marketplace add marbaji/marbaji-claude
claude plugin enable marbaji-claude@marbaji-claude
```
