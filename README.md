# marbaji-claude

Mo's personal Claude Code skills marketplace.

## Skills

### /inventory-checker
Displays a complete inventory of all installed Claude Code components — MCP servers (local and cloud, with status), plugin marketplaces, available skills (grouped by marketplace), npm/Python/Homebrew packages, and CLI tools.

### /obsidian-memory
Project-first session memory using Obsidian. Loads context at session start, updates project docs and current-focus at session end, and writes lean session logs. Presents a summary with categories (ChalkTalk vs Personal) for approval before writing.

## Install

```bash
claude plugin marketplace add marbaji-claude --source github --repo marbaji/marbaji-claude
claude plugin enable marbaji-claude@marbaji-claude
```
